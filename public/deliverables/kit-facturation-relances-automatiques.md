## 🔌 Import des workflows
1. Téléchargez les fichiers depuis votre espace Bazario.
2. Dans n8n / Make / Zapier : **Import** → sélectionnez le fichier.
3. Renseignez vos identifiants (API keys) dans les nœuds marqués.
